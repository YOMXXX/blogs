当智能体要处理的任务从「回答一个问题」变成「重建一个完整程序系统」，真正的瓶颈悄然转移了：不再是模型想不想得明白，而是运行本身有没有人管。9 月 29 日，Meta 与普林斯顿的研究者在 arXiv 上发布的论文《Thinking Before Thinking: Scaling Agentic Inference Through Meta-Reasoning》（arXiv:2609.38147），把「管住一次运行」这件事本身变成了一种可扩展的推理形式，作者阵容包括 Jason Weston、Rob Fergus、Ruslan Salakhutdinov 等老牌研究者，分量不容小觑。

## 一次长运行里挤满了隐藏的决策

论文从一个人人遇到过但很少有人形式化的问题出发：智能体每执行一步，都面临一层任务之上控制选择。当前这条写了一半的思路值得继续投入吗？还是该推倒重来另起炉灶？手里的预算还剩多少、够不够支撑下一条分支？什么时候该宣布收工？这些选择在现有 harness 里要么被硬编码的启发式规则代劳，要么被默认流程悄悄替模型做了。

作者把这类选择统一起来，提出 agentic meta-reasoning：在推理时引入一个显式的、结构化的控制过程。整个框架分两层。下层是 worker，负责任务级计算——写代码、跑测试、推导证明，干的是传统意义上「智能体的活」。上层是 controller，它做四件事：整合运行至今已经确立的结论、探索下一步可选项、在剩余预算约束下评估每个选项的价值、把选中的工作连同从持久记忆中取出的上下文一起分派给 worker。

结构上最关键的设计是第三点之后的那个细节：controller 在两次决策之间不回放完整历史，只携带一份运行过程的紧凑账本。这个设计直接回应了长程智能体最现实的工程约束——如果控制器每次都要吞下全部轨迹，它的上下文和开销会随任务长度爆炸，整个方案在真实的复杂度增长面前不攻自破。

## 数字说话：控制结构本身就是竞争力

实验设计里最值得称道的是基线的公平性。作者构造了一个 Direct Control Agent：使用与元推理框架完全相同的 worker、完全相同的计算预算，唯一的区别是没有结构化的控制推理。这个基线把「收益来自更强的模型或更多的算力」这条最常用的质疑路径彻底堵死——所有差距都只能归因于控制结构。

主战场 ProgramBench 通过程序重建任务测试长程智能体能力，结果相当有戏剧性。GPT-5.5 驱动的元推理框架拿到 71.5%，而作为对照的 Codex 是 58.0%，差距高达 13.5 个百分点。换成 Opus 4.8 时，元推理达到 67.2%，对 Claude Code 的 65.5% 只有 1.7 个百分点的优势。这组对比透露出一个微妙的事实：Claude Code 作为产品级 harness 已经在控制层面做了大量工程打磨，留给外挂控制器的增量空间更小；而通用编码代理的默认流程离最优控制还差得远。

在其他三类基准上——抽象推理、多领域长程推理、证明生成——元推理相对直接控制的平均增益稳定在 3.6 到 4.2 个百分点之间，且横跨三个前沿模型一致成立。这种跨模型、跨任务类型的稳定性，比任何单一基准上的大数字更能说明方法的普适性。

## 预算曲线才是这篇论文的真正论点

如果只看固定预算下的分数，这项工作会被误读成「又一个 harness 工程」。论文真正的论点藏在预算扩展曲线里：在测试覆盖的预算范围内，直接控制的性能会进入平台期，而元推理持续爬升。也就是说，把计算花在结构化控制上的回报不会像堆单步算力那样快速边际递减——任务越长、越复杂，控制层的杠杆率越高。

代价同样被如实报告：在小预算下，controller 的开销可能反噬收益。这符合直觉——当总预算只够跑几条分支时，为「决定怎么花」付出的算力占比过高，控制本身就成了奢侈品。元推理是给长运行准备的工具，短平快的任务用不上也不必用。

论文还用工件图（artifact graph）分析验证了机制：元推理框架确实更多地复用了早期工作成果，在多数设置下正确解的覆盖率更高，最终选择环节的增益则不均匀。这些证据把「为什么有效」从猜测推进到了可观测的行为层面。

## 工程意义：控制平面正在成为独立一层

把这篇论文放回更大的图景里看，它标记的其实是一个架构演化节点：智能体系统正在分化出独立于模型与工具之外的控制平面。过去一年业界反复验证了单步能力的快速通货膨胀——前沿模型在短任务上的差距越来越小；这篇论文的数据补上了另一半图景——长程任务上的差距主要由控制质量决定，而控制质量是可以工程化、可以独立扩展的。

对实践者而言，这篇论文给出的最可移植的思想不是完整框架，而是那个紧凑账本原则：控制器的状态必须是有界的。很多团队的 agent 编排在早期还能工作，跑长了就退化成灾难，根因往往是编排层被迫吞下全部历史。controller 只记账不回放的设计，值得写进每一个长程智能体系统的设计文档。

当「思考」本身已经足够便宜，「在思考之前先思考」就成了新的稀缺资源。这篇论文是第一个把这句话变成可测量、可扩展、可复现的系统化尝试。
