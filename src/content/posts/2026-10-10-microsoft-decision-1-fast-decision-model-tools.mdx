决策模型这个品类，在 2026 年秋天正式从「论文概念」变成了「货架商品」。继 OpenAI 给 GPT-6 Luna 配上 Decisions 模式、开源圈冒出 Strands-Decider 2B 之后，微软 10 月 9 日发布了自家的 Microsoft-Decision-1：一个把「结构化拍板」这件事做到延迟与成本双极限的专用模型。上架当天即开放 Microsoft Foundry 与 OpenRouter 双渠道，诚意给得很足。这篇速评把它拆开看：能干什么、不能干什么、以及同一个星期里那篇攻击论文给它泼的冷水。

## 一、它是什么：给选项打分的专用引擎

Decision-1 的定位与 LLM 完全不同：不给它开放式任务，而是给它一段文本加一组调用方定义的选项（yes/no、多选、评分制，或者给 AI 回复与 Agent 动作打分的量规），它对每个选项输出一个**校准过的概率**。校准是关键词——官方强调 90% 的预测在代表性样本上就该对九成，概率本身是 API 的一部分，应用可以直接拿它决定「执行、搁置还是转人工」。

底座是 Qwen3.5-9B 后训练，做的是单遍决策评分；微软预告后续会迁移到 MAI 和 OpenAI 的底座上再出一版。模型已在 Microsoft Foundry 模型目录和 OpenRouter 上架，后者意味着接入只需要改一个 base URL。

## 二、数字盘一遍：快、稳、便宜

**基准面**：官方跑了一个 36 基准、近十五万道题的横评，所有基准对训练保持盲态，覆盖路由、排序、长上下文、多语言、分布外、推理与安全。结论是准确率第一；在公开榜 JevBench 上的头部模型拉出来重测，Decision-1 仍是最好的那个——泛化性这块它用「盲测集」做了防过拟合的论证，比单榜刷分可信。

**延迟面**：P50 延迟比 GPT-6 Sol 快约三十五倍，比同品类第二名 Quyet-1.0-Large 快四点五倍。串行决策链是这个优势的放大器：官方举的账是二十个串行决策每步多一百毫秒就多两秒——反过来，每步省一百毫秒，长链 Agent 的体感差异就是秒级对亚秒级。

**稳健面**：同一请求做八类扰动（改写选项描述、重排、洗牌、改键名、加格式噪声等），平均翻转率 1.3%，其中改写与重排两类零翻转。这组数字对「生产环境的表述漂移」场景非常关键——用户不会用标准句式说话，决策引擎必须对此免疫。

**安全面**：5250 条请求、11 个基准，覆盖有害内容、越狱与提示注入，结论是能拒绝有害请求同时保持高可用性。注意这与对抗鲁棒是两回事，下文细说。

**价格面**：输入每百万 token 0.042 美元，输出免费。对照 Xbox Research 的实测——一万多条开放反馈分类，质量与 GPT-6 Sol 打平，速度快十四倍、成本低两百倍——这个价差在批量场景里不是优化，是量级。

微软还给了几组内部实测：Copilot 团队用它做对话质量评估，与 GPT-5.6 Luna 相当且快一百倍；Microsoft Discovery 的自适应重规划里，Decision-1 打分比 LLM 打分一致性高四十六倍，整个重规划循环快近四倍。科学发现场景里「打分一致性」决定实验方向，这个四十六倍可能是全场最重的数字。

## 三、能力边界：它不能做什么

三个硬边界要写进选型文档：

其一，**无解释**。输出是概率，不是理由。需要可审计决策链的场景，解释那一半还得靠主模型或日志回放。

其二，**选项集封闭**。它只在给定选项内分配概率，处理不了「都不对」之外的新选项。开放式判断任务不适用。

其三，**校准依赖分布**。概率的置信含义建立在代表性样本上，分布漂移严重的场景需要定期校验。

## 四、同一周的冷水：guardrail 位置要想清楚

Decision-1 发布的前一天，南加州大学团队的论文《One Word Opens the Gate》系统攻击了「决策模型当护栏」的架构：六行服务器日志文本能把 fail-open 率从零拉到六成三，一个误导性的选项名能把四款模型的失守率推到九成三以上，且所有已测防御（包括置信度升级）全部失效。微软博客里稳健性测试测的是等价扰动，而那篇论文的攻击面是非等价输入——两者不重叠，意味着官方数据不构成对这类攻击的免疫证明。

这不影响 Decision-1 在分流、路由、标注、评分场景的价值，但给「把它放在 Agent 安全关口当最终闸门」的用法画了问号。合理的架构是：Decision-1 做快速分流，确定性规则引擎做硬约束，人工复核兜住低置信尾部。它是加速器，不是保险柜。

## 五、接入建议

想试水的团队按这个顺序走：先在 OpenRouter 上用现成 key 跑通一个分类或路由任务，对照现有方案测准确率与延迟；量跑起来后再迁 Microsoft Foundry 看企业合规与价格；最后对照 option-channel 论文的攻击清单过一遍选项输入源。同品类的开源备选还有 Strands-Decider 2B、H2O-Lightning-4B、deck-31B 可做自托管对照。决策模型的货架已经摆满，比的不是谁更新，而是谁的位置摆得对。

最后一个值得记录的细节：微软在公告末尾列了十六个候选场景，从代码扫描、搜索相关性到机器人动作选择，覆盖面几乎等于「Agent 工作流里所有需要表态的环节」。这个清单本身可以当作产品评审的 checklist 用——逐条问自己的系统里这些环节现在由谁承担、成本多少、错了的代价多大，答案自然会把 Decision-1 放进该放的位置。工具很便宜，位置想清楚才贵。
