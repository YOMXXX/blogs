语音输入正在悄悄成为 AI 时代的新键盘，但市面上的选择一直是个哑铃：一头是订阅制闭源的 Wispr Flow，体验好但语音要过别人的服务器；另一头是 macOS 自带听写，免费但模型和功能都停在「能用」级别。10 月 11 日登上 Show HN（140 个赞）的 BetterWispr 想填补中间的空档：**免费、开源、本地运行，同时把商业产品的体验细节学了个遍。**

## 一、核心体验：按住说话，松手上屏

BetterWispr 的交互一句话就能说清：在任何应用里按住 Option 加空格说话，松手，文字落进光标处。支持按住说话与点击切换两种模式，快捷键可自定义（Command、Option、Control 组合或 F 键都行）。粘贴被目标应用拦截时，文本自动退回剪贴板，保证「说什么都不丢」。这套「全局快捷键 + 落进原应用」的设计与 Wispr Flow 完全同构，学习成本为零。

## 二、模型矩阵：九种本地引擎随意换

这是它区别于大多数听写工具的地方。内建九种模型：Apple 语音（最省资源）、Parakeet TDT v3（英语、日语加 25 种欧洲语言，当前开源转写第一梯队）、Parakeet Japanese、Whisper Large v3 Turbo、WhisperKit、Sarvam AI 等，还可以填自己的 API 密钥接入 Sarvam、Smallest AI 或任何 OpenAI 兼容端点。模型下载一次后完全离线，界面明确写着：**Nothing is uploaded，什么都不上传**。

对中文用户，Whisper 系是多语种混说场景下更稳的选择；对追求低延迟的英语用户，Parakeet 的速度优势明显。一个工具里塞下完整的模型光谱，等于把「选哪家转写引擎」的决策权还给了用户——这在商业产品里通常意味着不同的订阅档位。

## 三、清理与风格：说得乱，发得干净

「说得乱、发得干净」是这类工具的灵魂。BetterWispr 提供三档清理：None 保留每个字；Light（默认）去掉英语口头禅、重复与口误；Medium 在本地调用 Apple Intelligence 或 Ollama 进一步润色通顺。风格按应用配置：私人聊天用「随意」档（去掉句末句号）、工作软件用「正式」档、邮件用「商务」档，目前语气功能覆盖英语。

语音命令也齐了：说话时喊逗号、问号、新段落，标点即刻上屏；喊一句 scratch that，删掉刚说的最后一句。再加上自定义词表——人名、术语加进去，纠正一次就永久学会——日常高频词汇的上屏准确率会随使用时间持续变好。历史记录里保留原始转写与清理后文本两版，随时可用「原文」一键还原，且历史可整体关闭。

## 四、会议纪要：本地版的 Notetaker

意外之喜是会议纪要功能。Notetaker 把你的麦克风转写标记为「我」，把其他应用播放的声音标记为「对方」，与手写笔记并排呈现，随后由 Apple Intelligence 或 Ollama 在本机生成摘要、决议与行动项。示例场景里的输出相当成型：行动项「周四前完成 QA 签收」「周五交付导出」「今天告知支持团队」条条可执行。全程无云端、无需接入会议软件，隐私敏感的线上会议场景几乎无竞品。局限也直白：只能听见你电脑里的声音，线下会议不适用。

## 五、上手成本：十分钟的真实接入流程

以一台 Apple Silicon 的 MacBook 为例，完整的接入路径大约十分钟。官网下载对应芯片的安装包，首次启动后在系统设置里授予辅助功能与麦克风权限——全局快捷键注入文本依赖这两项。接着挑模型：磁盘紧张就选 Apple 语音（零下载），追求准确率下载 Parakeet TDT v3，多语种混说上 Whisper Large v3 Turbo；模型文件本地存放，切引擎不用重装。最后花两分钟配风格：给微信设「随意」、给邮件客户端设「商务」、给编辑器设「无清理」，词表里加上项目里的人名与缩写。

实际写一周之后的价值在数据面板里：它统计你累计说了多少字、平均语速、清理功能帮你省了多少次按键、连续使用天数——这些数字全部从本地历史算出，不上传。对了，「scratch that」这个语音撤销命令值得练成肌肉记忆，它是口误场景下最快的一颗后悔药。

## 六、安全与工程细节

供应链纪律值得点名：更新通过 GitHub Releases 走 Sparkle 框架分发，安装前校验 EdDSA 签名，不匹配即拒绝。统计面板（说了多少字、语速、清理省了多少字、连续使用天数）全部从本地历史计算。代码 Apache 2.0 开源，macOS 14 起步，Apple Silicon 推荐，Intel 版本也提供下载。

## 六、横向对比与结论

与 macOS 自带听写相比，BetterWispr 在模型可选性、清理质量、词汇记忆、会议纪要四个维度全面领先，代价是要装一个第三方应用。与 Wispr Flow 相比，核心体验同构，但免费、开源、本地化；劣势在清理与语气功能的语言覆盖（目前偏英语）和商业产品的持续迭代速度。与 MacWhisper、superwhisper 这类 Whisper 前端相比，BetterWispr 的差异化在「输入法级」的集成体验——词表学习、按应用风格、语音命令、会议纪要，这些功能把它和「转写工具」区分开来。

结论：如果你在 macOS 上有大量打字场景，且对「语音上传云端」有顾虑，这是当前免费选项里完成度最高的一个。中文重度用户先降低对润色功能的预期，把 Parakeet 或 Whisper 调好，核心的「按住说话、松手上屏」已经足够值回安装时间。

再往大处看一层，BetterWispr 的出现是本地语音栈成熟的一个信号：Parakeet TDT v3 这类开源转写模型的准确率已经逼近云端服务，Apple Intelligence 与 Ollama 让润色和摘要也能在端侧完成，剩下的只是把体验细节缝合好——而这恰恰是开源社区最擅长的事。当转写、清理、摘要三段全部本地化之后，「语音输入」和「键盘输入」之间的隐私差距就归零了，剩下的选择只取决于你说话快还是打字快。对开发者还有一个隐藏福利：它是 Apache 2.0，想给自己的工作流定制功能（比如接入自定义热词服务、把纪要推送到任务系统），直接读源码改就是。
